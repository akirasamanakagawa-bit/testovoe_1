# Инструменты геолокации ооооо
 Современные смартфоны определяют геолокацию (местоположение) с помощью различных систем: 
* GPS-модуль,
* акселерометр,
* триангуляция по сотовым вышкам, 
* датчик освещенности.  
  
### GPS-модуль
    GPS – спутниковая система навигации, которая позволяет определить местоположение устройства с GPS-приёмником. 
GPS-сигнал бывает недоступен: внутри бетонного здания, на узкой улице, состоящей из высоких домов. В таких условиях сигнал от спутников не «долетит» до вашего устройства. В таких случаях ваш телефон начинает использовать другие способы определения местоположения

### Акселерометр
    Акселерометр - электронный компонент внутри телефона. Регистрирует усилия, которые изменяют положение телефона в пространстве.
Когда смартфон теряет соединение с GPS-спутником, он «запоминает» последние координаты. Дальнейшие изменения в геолокации телефон регистрирует с помощью акселерометра. 

### Триангуляция по сотовым вышкам
    Триангуляция по сотовым вышкам - определение геолокации устройства на основе данных станций оператора мобильной связи.
Смартфон измеряет время прохождения сигнала от трех базовых ближайших станций. Местоположение определяется в точке, где пересекаются все три радиуса.

### Датчик освещенности
Датчик освещенности используется некоторыми приложениями для вызова такси. Приложение анализирует данные от датчика и сопоставляет их с временем суток, позицией солнца на небе и ближайшими объектами.

# Интерфейсы геолокации
    Интерфейсы геолокации — это интерфейсы в браузерах, которые позволяют разработчикам получать информацию о местоположении устройства пользователя.
Интерфейсы геолокации используют для создания приложений, ориентированных на местоположение (цифровые географические карты, такси и др.)
Для доступа к геолокационным данным мобильная платформа oiOs представляет два отдельных интерфейса:
* [LocationServices](https://ru.wikipedia.org/?l=) для получения данных от GPS-модуля и триангуляционных механизмов.
* [LocationAdjustments](https://ru.wikipedia.org/?l=) для получения данных от акселерометра.
